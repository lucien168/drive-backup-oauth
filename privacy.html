Privacy Policy

Applies to the personal Google OAuth application named rclone operated by GitHub user lucien168 for self-use. This is not the official rclone website and is not affiliated with the rclone project or Google.

Last updated: 2026-09-27

1. Who uses the app

The app is used only by its owner, with the owner's own Google account. It is not offered to other users.

2. What data is accessed

Through the Google Drive API, the app accesses files and file metadata (such as names, sizes, modification times and checksums) in the owner's own Google Drive.

3. How the data is used

Data is used only to upload the owner's encrypted backups to the owner's Google Drive and to verify that those uploads are complete and correct. Backups are encrypted on the owner's computer before upload.

4. Storage of credentials

OAuth credentials and tokens are stored only on the owner's local computer, in the rclone configuration. They are not sent to or stored on any other server.

5. Sharing

No data is sold, shared, or transferred to any third party. There is no analytics, advertising, or tracking. Data is not used to train AI/ML models.

6. Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

8. Contact

Via the GitHub profile github.com/lucien168, or the support email shown on the Google consent screen.
