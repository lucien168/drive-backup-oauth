Personal Drive Backup (rclone)

This page describes a private, single-user Google OAuth application named rclone in the Google Cloud project of the GitHub user lucien168.

This is not the official rclone website and is not affiliated with or endorsed by the rclone project or Google. rclone is open-source software; its official site is rclone.org.

What the app does

  • The owner uses the open-source tool rclone, on the owner's own computer, to write encrypted backups into the owner's own Google Drive.
  • The app reads Google Drive files and file metadata only to upload backups and to verify that they were uploaded correctly (e.g. listing, sizes, checksums).
  • OAuth credentials are stored only on the owner's local computer. There is no server, website backend, database, or third-party service involved.
  • The app is for personal use only and is not offered to the public.

See the Privacy Policy.
